# Task 3.1: Bảng `tasks` + RLS

**Trạng thái:** ✅ Xong (merged 28/11/2026) · **Độ lớn:** S · **Nhánh:** `feat/tasks-table` · **PR:** [#11](https://github.com/cngvy286-coder/stayon/pull/11)

## Mục tiêu
Tạo bảng **`tasks`** trên Supabase để lưu công việc của người dùng (tên việc, hạn chót, trạng thái, độ ưu tiên),
có **RLS** để mỗi người chỉ thấy và sửa được việc của mình. Đây là nền cho các Task 3.2–3.4.

## Phạm vi

  - Cập nhật README: "Thời khóa biểu" → ✅ Xong, "Công việc & tiến độ" → ⏳ Đang làm (đã hẹn từ Task 2.6).

  - Giao diện danh sách / thêm việc → Task 3.2.
  - Đổi trạng thái, sửa, xóa → Task 3.3.
  - Dashboard % hoàn thành → Task 3.4.
  - Nhắc trước hạn chót → Task 4.1.

## Cách làm
Migration `supabase/migrations/<timestamp>_create_tasks.sql`, theo cùng mẫu bảng `events` (Task 2.1).

**Các cột**

| Cột | Kiểu | Ghi chú |
|---|---|---|
| `id` | uuid | khóa chính, tự sinh |
| `user_id` | uuid | mặc định `auth.uid()`, xóa user thì xóa theo |
| `title` | text | bắt buộc, 1–200 ký tự (sau khi bỏ khoảng trắng) |
| `note` | text | không bắt buộc, ≤ 1000 ký tự |
| `due_at` | timestamptz | hạn chót, không bắt buộc (UTC) |
| `status` | text | `todo` (Cần làm) · `doing` (Đang làm) · `done` (Xong), mặc định `todo` |
| `priority` | text | `low` (Thấp) · `medium` (Vừa) · `high` (Cao), mặc định `medium` |
| `completed_at` | timestamptz | **tự động**: lúc chuyển sang `done` thì ghi thời điểm, chuyển khỏi `done` thì xóa. Dùng cho dashboard (Task 3.4) |
| `created_at`, `updated_at` | timestamptz | `updated_at` tự cập nhật (dùng lại `public.set_updated_at()`) |

**Bảo mật**
- RLS cho select / insert / update / delete, chỉ được thao tác trên dòng có `user_id = auth.uid()`.
- Quyền theo cột:
  - Khách (`anon`) không có quyền gì.
  - Người đã đăng nhập chỉ được ghi `title`, `note`, `due_at`, `status`, `priority`.
  - `user_id`, `completed_at` và các mốc thời gian do database tự điền.
- Trigger `completed_at` chạy với quyền của bảng, có `search_path = ''` giống các hàm trước.

**Index**: `(user_id, status, due_at)` cho truy vấn "việc chưa xong của tôi, sắp theo hạn".
